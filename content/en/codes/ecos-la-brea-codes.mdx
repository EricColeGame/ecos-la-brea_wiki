## Common Issues When Redeeming Ecos La Brea Codes

Even when you have a valid code, things can go wrong. Here's a troubleshooting guide based on the most common player-reported issues:

### Code Not Working

- **Double-check capitalization** – Codes are case-sensitive
- **Remove extra spaces** – Copy-paste errors often include trailing spaces
- **Check expiration** – The code may have expired
- **Verify your region** – Some codes are region-locked and won't work in all markets

### Reward Not Appearing

- **Check your in-game mailbox** – Rewards don't always appear in inventory directly
- **Restart the game** – A simple restart often triggers reward delivery
- **Wait a few minutes** – Server delays can hold up reward processing

### Already Redeemed Error

Each Ecos La Brea code is typically limited to one redemption per account. If you see an "already redeemed" message, that code has already been used on your account — you won't be able to use it again.

| Error Message | Likely Cause | Solution |
|---------------|-------------|----------|
| Invalid Code | Typo or expired | Re-enter carefully or find new code |
| Already Redeemed | Used before | Cannot be reused |
| Region Restricted | Geographic lock | Check for region-specific codes |
| Reward Pending | Server delay | Wait and check mailbox |
